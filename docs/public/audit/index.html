Execution Trust Boundary Policy

Trusted Maintainer Sandboxes

Maintainer-controlled sandboxes and main-branch cache-publish jobs hold read and trunk write credentials for build.smithers.sh and satisfy merge and release gates.

Untrusted Contributor Runs (Encouraged)

Non-maintainers can run local or sandboxed checks, Uphill audits, and repro flows freely. Untrusted runs read shared cache hits but never write trunk keys or skip gates.

Person-Only Governance

Agents connect via https://smithers.sh/api/mcp using short-lived attenuated tokens. Merging, committing TODOs, publishing releases, and secret edits remain person-only.
