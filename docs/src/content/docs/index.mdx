```bash
# One-shot text (default)
npx claude-p "Reply with the single word OK."

# Structured JSON result
git diff HEAD~1 | npx claude-p --output-format json "Summarize this diff."

# Live per-message JSONL stream (--verbose required)
npx claude-p --output-format stream-json --verbose "Audit src/" | jq .

# Long-lived multi-turn daemon over NDJSON
printf '%s\n' '{"type":"user","message":{"role":"user","content":"List the Zig modules."}}' \
  | npx claude-p daemon
```

## Design principles

<CardGrid stagger>
  <Card title="Zero ~/.claude mutation" icon="approve-check">
    Every hook script, FIFO, and inline <code>--settings</code> payload lives inside a per-run
    <code>$TMPDIR/claude-p-&lt;pid&gt;-&lt;rand&gt;/</code> directory and is deleted on exit.
  </Card>
  <Card title="Hooks, not screen scraping" icon="terminal">
    <code>SessionStart</code>, <code>UserPromptSubmit</code>, and <code>Stop</code> drive the state
    machine. Output comes straight from Claude's session JSONL transcript.
  </Card>
  <Card title="Real PTY, deterministic paste" icon="rocket">
    <code>zmux.NativeSession</code> runs a real <code>forkpty</code> session. Prompts stream in
    ≤ 512 B UTF-8-safe bracketed-paste chunks so macOS <code>TTYHOG</code> never drops bytes.
  </Card>
  <Card title="Verified prebuilt binaries" icon="seti:lock">
    <code>scripts/install.js</code> downloads platform binaries from GitHub Releases and checks
    their SHA-256 digest against <code>SHA256SUMS</code> before writing to disk.
  </Card>
</CardGrid>
